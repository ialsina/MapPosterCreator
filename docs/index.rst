Map Poster Creator
==================

Map Poster Creator creates minimalist road-map posters from OpenStreetMap
shapefiles and a GeoJSON boundary. It renders roads, water, and green areas
with a selected colour scheme and writes PNG files.

This repository is a fork of the original `k4m454k/MapPosterCreator
<https://github.com/k4m454k/MapPosterCreator>`_. See :doc:`project-history`
for provenance, licensing, and scope.
